O código vem gravado de fábrica no controle e tem o número de série e o botão apertado. No cadastro, a central guarda esse código na memória. Depois, ela abre o portão sempre que recebe um código igual a um dos guardados.

Como o conteúdo nunca muda, um copiador que grave um aperto consegue repetir o sinal e abrir o portão. Por isso o rolling code é mais seguro. Muitas centrais aceitam os dois tipos.
